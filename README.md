# Contao Skeleton Bundle

![Contao Skeleton Bundle — starter bundle for modern Contao projects](.github/assets/contao-skeleton-bundle.png)

A starting point for modern Contao bundles by [Heimrich & Hannot](https://github.com/heimrichhannot).

Includes shared coding guidelines and configuration for Easy Coding Standard, PHPStan and Rector.

To get started, copy this skeleton into your own repository, add your bundle's Composer configuration and source files, and adapt the tooling to your project. See [AGENTS.md](AGENTS.md) for development conventions.
